📋 Google AdSense Readiness Checklist

AdSense apply karne se pehle kam se kam kuch hafte consistent traffic/content hona chahiye. Technical side ka status:

  • ✅ Privacy Policy, Terms, About, Contact pages — mojood hain
  • ✅ Har page par unique Title Tag + Meta Description + Canonical URL
  • ✅ robots.txt + sitemap.xml — live hain
  • ✅ Security Headers (X-Content-Type-Options, HSTS, X-Frame-Options, Referrer-Policy) — vercel.json mein set hain
  • ✅ HTTPS — Vercel se automatic
  • ✅ Mobile-responsive/viewport — sab pages par hai
  • ⏳ Google Analytics (GA4) — hook ready hai (analytics-config.js), sirf Measurement ID daalna baaki hai jab GA4 property banayein
  • ⏳ Google Search Console — property verify karna baaki hai (site ownership verify)
  • ⏳ Structured Data (JSON-LD) — abhi nahi hai, listings ke liye add kiya ja sakta hai
  • ⏳ Genuine traffic/content history — AdSense apply karne se pehle kuch hafte organic use zaroori hai
  • ❌ ads.txt — sirf AdSense approval milne ke baad, publisher ID ke sath add hoga

Apply kab karein: jab site par kuch hafte se consistent real ads/traffic ho, tab google.com/adsense se apply karein. Approval milne ke baad publisher ID yahan (future update) daal sakte hain.
